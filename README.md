## 클래스 소개

새벽에 혼자 쓰기로 마음먹어도 대개 사흘이면 멈춥니다. 선릿모닝은 매일 아침 5시 50분, 줌에서 각자의 자리에 앉아 30분을 함께 쓰는 시간입니다. 혼자 쓰는 시간인데도 외롭지 않고, 그래서 이어집니다.

잘 쓰지 않아도 됩니다. 검열 없이 떠오르는 대로, 지우지 않고 멈추지 않고 씁니다. 그 안에서 **빛나는 돌멩이**를 건지는 것이 이 시간의 목적입니다.

| 구분 | 내용 |
|------|------|
| 기간 | 8월 3일 ~ 28일 (월~금) |
| 시간 | 새벽 5시 50분부터 30분간 |
| 방식 | 줌 (오디오 off, 화면 on) |
| 참가비 | 2만원 |
| 쉬는 날 | 토·일·법정공휴일 |

신청은 네이버 폼(`https://naver.me/GcAknJnT`)으로 연결됩니다.

## 구조

```
sunlit-morning/
└─ index.html    # 단일 파일 랜딩 (외부 의존: 구글 폰트 · 네이버 신청 폼 링크뿐)
```

이미지·스크립트 없이 HTML 한 장으로 완결됩니다. 배경의 별과 구간을 잇는 파도는 전부 CSS·인라인 SVG입니다.

## 배포

GitHub Pages — `main` 브랜치 루트(`/`)를 그대로 서빙합니다. 푸시하면 곧 반영됩니다. 워크플로·넷리파이 연동은 없습니다.

## 이 레포가 따로 있는 이유

이 페이지는 원래 디퍼 언브랜딩 과제로 만들어 [`deeper-haetsal`](https://github.com/POGNARU/deeper-haetsal)의 `assignment/sunlit-morning.html`에 있었습니다. 2026-07-17에 **독립 레포로 분리**했습니다.

과제 아카이브 안에 두면 주소가 `.../deeper-haetsal/assignment/sunlit-morning.html`이 되는데, 단축 주소로 공유해도 주소창에는 이 긴 주소가 남습니다. 뒷자리를 지우면 `/assignment/` 목록이 열려 **디퍼 과제 전부가 처음 온 손님에게 노출**됩니다. 모집 페이지가 개인 아카이브 안에 세 들어 사는 구조 자체의 문제라, 단축 주소로는 막을 수 없었습니다.

독립 레포로 옮기면 뒷자리를 지워도 `https://pognaru.github.io/` → 404. 나루의밤(`bamnaru`)이 이미 쓰던 방식 — **클래스는 자기 레포를 갖는다** — 과 같아졌습니다.

`deeper-haetsal` 쪽 사본은 과제 기록으로 그대로 남되 `noindex`가 걸렸고, 그 주소는 더 이상 공유하지 않습니다. **두 파일은 이제 각자 갑니다** — 모집 내용을 고칠 때는 이 레포만 고치면 됩니다.

## 운영 규칙

- **주소를 고정해 매월 갱신합니다.** 기수마다 새 파일을 만들지 않습니다. 검색 신뢰가 쌓이고, 인스타 프로필 링크를 한 번만 걸면 되고, 이미 뿌린 링크가 늘 최신 달을 가리킵니다.
- 매달 바뀌는 것은 **모임 안내의 기간** 한 줄과, 폼을 새로 만들 경우 **신청 버튼 주소**입니다.
- 같은 문구가 인스타 카드 8번과 캡션(볼트 `클로드 에이전트/윤슬의 기록/260715 선릿모닝 인스타 카드뉴스.md`)에도 있으니 함께 맞춥니다.
- **검색을 허용합니다** (`noindex` 없음). 모집 페이지라 찾을 수 있어야 하고, 사적 정보가 없어 안전합니다. `og:url`은 이 레포 주소를 가리켜야 합니다 — 옛 주소가 남으면 공유 미리보기가 아카이브를 물고 갑니다.
- 푸터는 `POGNARU STUDIO`만 씁니다. 손님이 보는 자리라 디퍼를 병기하지 않습니다.
- **돌아가기 링크를 넣지 않습니다.** 공유용 단독 랜딩이라 링크를 받은 사람이 디퍼 아카이브로 타고 들어갈 자리를 만들지 않습니다. (`deeper-haetsal`에 남은 과제 기록 사본에는 `← 과제 목록`이 있습니다 — 그쪽은 아카이브 안에서만 도니까요.)
